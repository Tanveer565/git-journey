Git & GitHub Crash Course for Beginners [2026]:-

PART 1: THE SETUP
1 : first download git from chrome
2 : Started using git bash as command line

3 : Using and learning git bash :-
A: going into a folder
$ cd Desktop

B: Creating a directory
$ mkdir git-one

C: currently in Desktop and going into a folder in it
$ cd git-one

D : Creating a file inside the open folder
$ touch one.txt
$ touch two.txt

E : Creating directory and file
$ mkdir myFolder
$ cd myFolder
$ touch three.txt


F : The cd .. command moves your terminal one folder up in the file system hierarchy, taking you out of the current folder and into its "parent" folder.
$ cd .. 

G : Opening the file or folder in your system file
$ explorer .

H : Telling git work on this folder now on ~/Desktop/git-one
$ git init
Initialized empty Git repository in C:/Users/Guestfamilyandfriend/Desktop/git-one/.git 
// it means git is now started tracking this folder and have made file .git to track 

I : 
Seeing all files
$ ls
myFolder/  one.txt  two.txt

seeing hidden files also
$ ls -a
./  ../  .git/  myFolder/  one.txt  two.txt

.git :- git tracks all the data like versions , changes , dates etc.

We have set the git and from now on git will be able to track every change.

Note :- We have Created a local repo and now we will create a remote repo with GitHub
