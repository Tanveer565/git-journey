PART 5 :- git Branching 
          BRANCHING:-Branching is a core feature in Git that allows you to create independent lines of development within the same repository. A branch represents a separate pointer to a specific commit, letting you work on new features, bug fixes, or experiments without affecting the main codebase.

          1] Main branch (often called main or master): The primary, stable version of your project
          2]Feature branches: Temporary branches for developing new features
          3]Isolated environment: Changes in one branch don't affect others until merged


Merged :- combining changes from branches in one branch

$git branch : To see the branch we have
$ git branch development : to create a new branch named development

$ git checkout development
